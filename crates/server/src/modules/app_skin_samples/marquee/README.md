Marquee: a big-screen streaming layout for Kinora.

A rotating hero of new titles, rails of landscape cards, full-bleed detail
pages with season tabs, and a matching player. Works with any theme; the
bundled "Marquee" theme is a near-black look with a red accent.

Options
- Rotate the hero: turn off for a still hero.
- Card size: small, medium or large cards on the home page.
- Accent colour: overrides the theme's primary colour for this skin.

Start your own skin from this one with `kinora skin new my-skin --from marquee`.
